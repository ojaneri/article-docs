# Skill categories

| Category | For |
|---|---|
| `build` | compiling the manuscript, class files, bibliography processing, length |
| `figures` | generating, exporting and placing figures and tables |
| `data` | acquiring measurements, running analysis, checking data provenance |
| `bibliography` | finding the literature, reference hygiene, metadata verification |
| `validation` | testing the paper's own argument: claims against evidence, statistics, citations, threats to validity |
| `collaboration` | syncing with a collaborative editor, merging co-author edits |
| `repository` | version control for the manuscript, anonymised copies, submission snapshots |
| `review` | reviewer reports, rebuttal assembly, marked-up revisions |
| `submission` | packaging, anonymising and submitting to the venue; preprints |
| `reproducibility` | artifact packaging, archiving, DOI minting |
| `process` | deadlines, author coordination, language passes, internal review rounds |
