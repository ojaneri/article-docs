# Skill categories

| Category | For |
|---|---|
| `build` | compiling the manuscript, class files, bibliography processing |
| `figures` | generating, exporting and placing figures and tables |
| `data` | acquiring measurements, running analysis, checking data provenance |
| `bibliography` | reference hygiene, deduplication, metadata verification |
| `collaboration` | syncing with a collaborative editor, merging co-author edits |
| `review` | handling reviewer reports, rebuttal assembly, diff-for-reviewers |
| `submission` | packaging, anonymising and submitting to the venue |
| `reproducibility` | artifact packaging, archiving, DOI minting |
| `process` | deadlines, author coordination, internal review rounds |
